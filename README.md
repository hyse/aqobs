# aqobs :: air quality observatory
higher resolution air quality map

网址 aqobs.com = www.aqobs.com

示例 www.aqobs.com/?lat=30.33&lon=120.43&scale=13.33

你可以直接修改中心点坐标 lat=北纬 lon=东经 scale=比例尺

不知道该填什么没关系，网页会自动定位

没有定位权限也没关系，滚动地图时 url 也会跟着变，存下这个 url 就是你要的地点和比例

不填比例尺也没关系，默认比例尺足以覆盖附近城区
